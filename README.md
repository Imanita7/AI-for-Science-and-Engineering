# AI-for-Science-and-Engineering
## Course Project
This repository contains my course assignments and programming projects.

### Assignment 2
#### TEMPERATURE CONVERSION
A python program that converts temperature from degrees celsius to degrees Fahrenheit, checking the temperature threshold and converting multiple temperatures using a loop and function.

### Assignment 3
#### STUDENT PERFORMANCE RISK PREDICTION
A machine learning project that investigates whether students' academic and behavioral information can be used to identify students at risk of poor academic performance.

### Assignment 4
#### STUDENT PERFORMANCE STATISTICAL ANALYSIS
This project uses Python to analyze the student performance dataset through descriptive statistics, covariance, correlation and data visualization.
It explores the relationship between previous-period grades (G2) and final grades (G3) and uses a simple linear model to estimate final grades from earlier academic performance.

### Assignment 5
#### STUDENT PERFORMANCE ML MODELS
This project uses the Student Performance dataset to build and compare two supervised classification models: *Logistic Regression* and *Random Forest*. The models predict whether students are at risk of poor academic performance based on relevant student features. Their performance is evaluated using accuracy, precision, recall and F1 score.

### Assignment 6
#### STUDENT PERFORMANCE CLUSTERING
This project applies K-Means clustering to the Student Performance dataset to identify groups of students with similar characteristics. It uses feature scaling, the Elbow Method, Silhouette Scores and data visualization to explore suitable clusters and interpret their characteristics.
